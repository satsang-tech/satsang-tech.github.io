CLIENT · MEDIA

Reader engagement — Tambola

Print promotion platform · built for a regional media group

A promotions engine for a newspaper's Tambola (Housie) reader campaign. It generates large print runs of uniquely numbered tickets, lets editors build custom prize categories on a visual grid, declares one winning number each day, and works out the winners automatically — with a claim-and-verification desk and anti-fraud checks at payout. Every ticket is unique, and every result is reproducible and auditable.

Ticket generation Print export Rules engine Claim verification Node.js · PostgreSQL
